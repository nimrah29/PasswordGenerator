🔐 React Native Password Generator

A simple React Native application that generates secure random passwords based on user preferences such as password length and character types.

The app allows users to include or exclude:

Lowercase letters

Uppercase letters

Numbers

Symbols

It uses Formik for form handling and Yup for input validation.

📱 Features

Generate secure random passwords

Custom password length (4–16 characters)

Toggle character types:

Lowercase

Uppercase

Numbers

Symbols

Form validation using Yup

Smooth checkbox UI using BouncyCheckbox

Copy password by long pressing

Clean mobile UI

⚙️ Installation

Clone the repository:

git clone https://github.com/your-username/password-generator.git

Move into the project folder:

cd password-generator

Install dependencies:

npm install
▶️ Run the Project

Start Metro bundler:

npm start

Run on Android:

npx react-native run-android

Run on iOS:

npx react-native run-ios
🧠 How It Works

User enters a password length

User selects character types

When Generate Password is pressed:

The app creates a list of allowed characters

A random character is selected repeatedly

A secure password string is generated

The password is displayed on the screen

🔑 Password Generation Logic

The password is generated by randomly selecting characters from the selected character sets.

Example logic:

characters = lowercase + uppercase + numbers + symbols

Then:

randomIndex = Math.floor(Math.random() * characters.length)

This is repeated for the desired password length.
